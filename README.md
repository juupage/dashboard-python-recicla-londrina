## 📋 Overview

O **Recicla Londrina** é um projeto acadêmico voltado à aplicação de conceitos de Ciência de Dados na investigação de questões relacionadas à gestão de resíduos sólidos urbanos.

A solução utiliza bases de dados públicas para estruturar análises, identificar padrões e desenvolver visualizações interativas que facilitem a interpretação de indicadores relacionados à coleta e à reciclagem no município de Londrina - PR.

O objetivo é transformar dados brutos em informações relevantes para a compreensão de desafios ambientais e urbanos.

## 🎯 Project Goals

- Identificar e reunir fontes de dados públicos.
- Realizar limpeza, tratamento e padronização dos dados.
- Desenvolver análises exploratórias (EDA).
- Extrair indicadores e identificar padrões.
- Construir dashboards para visualização dos resultados.
- Disponibilizar informações de maneira acessível e estruturada.

## 🚀 Getting Started

### Prerequisites

- Python 3.x
- Git
- Visual Studio Code (recomendado)

### Installation

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/dashboard-python-recicla-londrina.git
```

Acesse o diretório:

```bash
cd dashboard-python-recicla-londrina
```

Crie um ambiente virtual:

```bash
python -m venv venv
```

Ative o ambiente virtual:

**Windows:**
```bash
venv\Scripts\activate
```

**Linux / macOS:**
```bash
source venv/bin/activate
```

Instale as dependências:

```bash
pip install -r requirements.txt
```
